# 归物本 (Guiwu Cost Journal)

记录购买过的物品（尤其是电子产品），自动计算日均使用成本。单用户、本地运行。

---

## 技术栈

| 项目     | 选择            | 说明                      |
| ------ | ------------- | ----------------------- |
| 语言     | Python 3      | 标准库自带 SQLite 和 Tkinter  |
| 数据库    | SQLite        | 零配置、零服务，数据存为本地 `.db` 文件 |
| GUI 框架 | CustomTkinter | 基于 Tkinter，组件默认圆角，现代风格  |
| 图片处理   | Pillow        | 加载 PNG 图标               |
| 打包     | PyInstaller   | 打包为单文件 `.exe`           |

## 快速开始

### 安装依赖

```bash
pip install customtkinter pillow
```

### 开发模式启动

```bash
python -m guiwu
```

### 打包为 exe

```bash
pyinstaller GuiwuCostJournal.spec
```

打包后 `dist/GuiwuCostJournal.exe` 可直接运行。首次运行自动在 `C:\Users\<用户名>\.GuiwuCostJournal` 下创建数据库和窗口状态文件，后续重新打包不会丢失数据。

## 数据库设计

### items 表

| 字段          | 类型      | 必填  | 说明                                        |
| ----------- | ------- | --- | ----------------------------------------- |
| id          | INTEGER | ✓   | 主键，自增                                     |
| name        | TEXT    | ✓   | 物品名称                                      |
| image_type  | TEXT    | ✓   | 图标类型，对应 `assets/icons/` 下的英文文件名（不含 `.png`） |
| price       | REAL    | ✓   | 购买价格（元）                                   |
| buy_date    | TEXT    | ✓   | 购买日期，格式 `YYYY-MM-DD`                      |
| retire_date | TEXT    |     | 退役日期，格式 `YYYY-MM-DD`，空字符串表示现役             |
| notes       | TEXT    |     | 备注                                        |
| created_at  | TEXT    |     | 创建时间戳                                     |

### additional_entries 表

| 字段         | 类型      | 必填  | 说明                         |
| ---------- | ------- | --- | -------------------------- |
| id         | INTEGER | ✓   | 主键，自增                      |
| item_id    | INTEGER | ✓   | 外键，关联 `items.id`，删除物品时级联删除 |
| name       | TEXT    | ✓   | 附加项名称（如 "卖掉了"、"贴膜"）        |
| type       | TEXT    | ✓   | `"收入"` 或 `"支出"`            |
| amount     | REAL    | ✓   | 金额（元）                      |
| date       | TEXT    | ✓   | 日期，格式 `YYYY-MM-DD`         |
| created_at | TEXT    |     | 创建时间戳                      |

## 核心计算逻辑

```
净成本 = 购买价格 − 收入总额 + 支出总额
使用天数 = (退役日期 或 今天) − 购买日期  （最小 1 天）
日均成本 = 净成本 ÷ 使用天数
```

- **现役物品**：退役日期为空，使用天数 = 今天 − 购买日期，日均随使用时间实时变化
- **退役物品**：退役日期已填，使用天数固定，日均冻结不变

### 统计栏

| 统计项   | 计算方式                   |
| ----- | ---------------------- |
| 共 N 件 | 被筛选后的物品总数              |
| 总资产   | 筛选后**现役**物品的购买价格之和     |
| 日均总成本 | 筛选后所有物品各自日均成本之和        |

## 界面概览

### 主窗口

- 顶部蓝色统计卡片：显示物品总数、总资产、日均总成本
- 控制栏：筛选（全部/现役/退役）、排序（购买时间/价格/使用天数/日均成本）、升序/降序切换、添加物品按钮
- 卡片列表：可滚动，每张卡片显示图标、名称、使用天数和价格信息
- 卡片颜色区分：现役为绿色，退役为灰绿色
- 点击卡片 → 弹出编辑窗口

### 编辑/新建窗口

- 物品名称、图标选择（带图标浏览器弹窗）、购买价格、购买日期、退役日期、备注
- 退役日期通过复选框控制显示/隐藏，勾选后出现日期选择器
- 附加项列表：名称、收入/支出类型、金额、日期，每行可单独删除
- 底部：删除按钮（仅编辑模式）和保存按钮

### 日期选择器

- 输入框只读，点击弹出日历弹窗
- 支持年/月翻页，未来日期不可选，今天和已选日期高亮

## 图标管理

- 图标存放在 `guiwu/assets/icons/`，英文文件名（如 `laptop.png`、`phone.png`）
- `ICON_MAP` 字典将中文分类名映射到英文文件名
- 31 个预设图标类型对应 ICON_MAP 中的 30 个条目（28 个物品类型 + 1 个 `default` 占位图）
- 加载时校验文件是否存在，不存在则跳过该类型
- 图标格式：PNG，推荐透明背景

---

## 窗口状态持久化

窗口关闭时自动保存以下状态到 `.window_state.json`：
- 窗口位置和大小
- 当前筛选和排序选项
- 升序/降序状态

下次启动自动恢复。
