# 归物本 (Guiwu Cost Journal)

记录购买过的物品（尤其是电子产品），自动计算日均使用成本。单用户、本地运行。

---

## 技术选型

| 项目     | 选择            | 说明                      |
| ------ | ------------- | ----------------------- |
| 语言     | Python 3      | 标准库自带 SQLite 和 Tkinter  |
| 数据库    | SQLite        | 零配置、零服务，数据存为本地 `.db` 文件 |
| GUI 框架 | CustomTkinter | 基于 Tkinter，组件默认圆角，现代风格  |
| 图片处理   | Pillow        | 加载 PNG 图标               |
| 打包（可选） | PyInstaller   | 未来可打包为单文件 `.exe`        |

## 数据库设计

### items 表（物品主表）

| 字段          | 类型      | 必填  | 说明                                                       |
| ----------- | ------- | --- | -------------------------------------------------------- |
| id          | INTEGER | ✓   | 主键，自增                                                    |
| name        | TEXT    | ✓   | 物品名称                                                     |
| image_type  | TEXT    | ✓   | 图标类型，对应 `assets/icons/` 下的文件名（不含 `.png`），默认 `"_default"` |
| price       | REAL    | ✓   | 购买价格（元）                                                  |
| buy_date    | TEXT    | ✓   | 购买日期，格式 `YYYY-MM-DD`                                     |
| retire_date | TEXT    |     | 退役日期，格式 `YYYY-MM-DD`。NULL 或空字符串表示现役                      |
| notes       | TEXT    |     | 备注，选填                                                    |
| created_at  | TEXT    |     | 创建时间戳，自动生成                                               |

### additional_entries 表（附加项表）

| 字段         | 类型      | 必填  | 说明                         |
| ---------- | ------- | --- | -------------------------- |
| id         | INTEGER | ✓   | 主键，自增                      |
| item_id    | INTEGER | ✓   | 外键，关联 `items.id`，删除物品时级联删除 |
| name       | TEXT    | ✓   | 附加项名称（如"卖掉了"、"贴膜"）         |
| type       | TEXT    | ✓   | `"收入"` 或 `"支出"`            |
| amount     | REAL    | ✓   | 金额（元）                      |
| date       | TEXT    | ✓   | 日期，格式 `YYYY-MM-DD`         |
| created_at | TEXT    |     | 创建时间戳，自动生成                 |

## 核心计算逻辑

### 日均成本

```
净成本 = 购买价格 − 所有"收入"类附加项金额 + 所有"支出"类附加项金额
使用天数 = (退役日期 或 今天) − 购买日期
日均成本 = 净成本 ÷ 使用天数
```

- **现役物品**：退役日期为空，使用天数 = 今天 − 购买日期，日均随时间动态变化
- **退役物品**：退役日期已填，使用天数固定 = 退役日期 − 购买日期，日均冻结不变

### 统计栏

| 统计项    | 计算方式                   |
| ------ | ---------------------- |
| 共 N 件  | 所有物品总数                 |
| 现役 X 件 | `retire_date` 为空的物品数   |
| 总资产    | 所有**现役**物品的购买价格之和      |
| 日均总成本  | 所有物品（现役 + 退役）各自的日均成本之和 |

### 卡片布局规则

- **横条卡片**，纵向单列排列
- 卡片左侧显示物品图标（PNG）
- 现役物品：白色/正常背景
- 退役物品：灰色背景（不显示"已退役"文字）
- 卡片上**不显示操作按钮**
- **点击卡片** → 弹出编辑窗口

### 编辑/新建窗口

点击任意卡片进入编辑模式；点击主窗口「+ 添加物品」进入新建模式。两者共用同一表单组件：

```
┌─────────────────────────────────────────┐
│  编辑物品 / 添加物品           ✕ 关闭   │
│                                         │
│  名称:       [                    ]     │
│  图标:       [手机 ▼]                  │
│  价格:       [                    ]     │
│  购买日期:   [                    ]     │
│  退役日期:   [ 留空=现役          ]     │
│  备注:       [                    ]     │
│                                         │
│  ── 附加项 ───────────────────────     │
│  ┌────────────────────────────────┐     │
```

- 退役日期留空 = 现役，填写日期 = 已退役

- 底部「删除」按钮（红色）和「保存」按钮（绿色）
- 新建模式下不显示「删除」按钮

## 筛选与排序

### 筛选

下拉选择，三种选项：

- **全部** — 显示所有物品
- **现役** — 仅显示 `retire_date` 为空的物品
- **退役** — 仅显示 `retire_date` 不为空的物品

### 排序

两个下拉框：

| 排序字段 | 说明                    |
| ---- | --------------------- |
| 购买时间 | 按 `buy_date` 排序       |
| 购买价格 | 按 `price` 排序          |
| 使用天数 | 按 (退役日期或今天 − 购买日期) 排序 |
| 日均成本 | 按计算出的日均成本排序           |

排序方向：升序 / 降序，可切换。

## 图标管理

- 图标存放在 `assets/icons/` 目录
- 文件名 = 分类名 + `.png`，如 `手机.png`、`显卡.png`
- 程序启动时自动扫描该目录，获取可用图标列表
- `config.py` 中维护一份预定义图标类型列表，对应所有预设分类
- 若某个图标文件不存在，使用 `_default.png` 作为占位
- 图标格式：PNG（推荐透明背景，简笔画/线稿风格）
